# PokemonCards

A frontend project that displays Pokémon details in interactive cards.

## Features
- Search Pokémon
- View Pokémon details
- View Pokémon evolution
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- PokéAPI

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
